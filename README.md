# 김장 물가 알리미

KAMIS Open API 소매가격으로 김장 재료 예상 비용과 가격 흐름을 **주 1회 카카오 알림톡(또는 문자)** 으로 보내는 스크립트입니다.
Python 3.8 이상, 표준 라이브러리만 씁니다. 서버에서 cron 으로 돌고, 맥에서 push 만 하면 다음 실행 때 자동 반영됩니다.

```
KAMIS 소매가격(전국 평균) ─▶ kimjang_report.py ─▶ 메시지 + 알림톡 변수 ─▶ notify.py ─▶ 알림톡 ▸ (실패 시) 문자 ▸ 메일 ▸ 텔레그램
                                   │
                                   └─▶ data/ (messages·logs·prices.csv)
```

## 파일

| 파일 | 역할 |
|---|---|
| `kimjang_report.py` | 조회 → 계산 → 메시지 본문(`render`) → 알림톡 변수(`template_vars`) → 저장 → 발송 호출 |
| `notify.py` | 발송 채널. `.env` 에 값이 있는 채널만 동작 |
| `items.json` | 재료 목록·수량, 알림톡 슬롯 대응(`alimtalk`) |
| `run.sh` | cron 용. `git pull` → `.env` 로드 → `report` |
| `sample/` | 인터넷 없이 시험하는 가짜 응답 |
| `tests/` | `python3 -m unittest discover -s tests` (솔라피 호출 없이 변수·페이로드 검사) |

## 1. 인증 정보

```bash
cp .env.example .env
nano .env        # KAMIS 키, 솔라피 키, 발신·수신 번호, (알림톡) 채널 ID·템플릿 ID
chmod 600 .env
```

`.env` 는 `.gitignore` 에 들어 있어 커밋되지 않습니다.

## 2. 품목 이름 확인 (처음 한 번)

```bash
set -a; . ./.env; set +a
python3 kimjang_report.py codes
```

채소류·특용작물·수산물의 품목, 품종, 등급, 단위가 출력됩니다. `items.json` 의 `category`, `match_item`, `match_kind` 를 실제 출력과 맞추세요
(예: 쪽파는 품목 "파"·품종 "쪽파"). 단위가 다르면(고춧가루 1kg vs 600g) 스크립트가 자동 환산하고, 개/포기처럼 무게로 바꿀 수 없는 경우만 "단위 불일치"로 알려 줍니다.
수량(`qty`)은 부모님 댁 김장 기준으로 고치세요.

## 3. 리포트 만들기

```bash
./run.sh --no-send                 # 발송 없이 생성만 (처음엔 이걸로 확인)
./run.sh                           # 생성 + 발송
./run.sh --fixture sample --no-send # 인터넷 없이 가짜 숫자로 시험
python3 kimjang_report.py vars --fixture sample   # 알림톡 변수 값만 출력 (템플릿 검수·테스트 발송용)
```

결과는 `data/` 폴더에 쌓입니다.

- `messages/날짜.txt` 문자·메일용 본문 (알림톡 실패 시 대체 문자로도 이 본문이 나감)
- `logs/날짜.json` 그날 조회한 원자료
- `prices.csv` 주차별 가격 누적. 엑셀에서 바로 열림

주말·공휴일에는 가격이 없으므로 가장 가까운 과거 평일 가격을 씁니다. KAMIS 는 공휴일에도 품목 목록은 주고 가격만 비우기 때문에
"재료 절반 이상에 숫자 가격이 있는 날"을 기준일로 고릅니다. 절반 미만이면 발송하지 않고 `[발송 중단]` 로그만 남깁니다.

## 4. 카카오 알림톡 (기본 채널)

### 템플릿 (2026-10 검수본)

```
[김장 물가 알리미] #{기준일} 주간 가격 정보

신청하신 김장 재료 가격 정보를 안내드립니다.

■ 기준: KAMIS 소매가격(전국 평균), #{가족기준}
■ 예상 재료비: 약 #{총액}
  (지난주 대비 #{주간증감}, 작년 대비 #{연간증감})

■ 재료별 가격
- 깐마늘 #{수량1} #{금액1} · 평년 대비 #{평년비1} · 지난주 대비 #{주간비1}
- 고춧가루 #{수량2} #{금액2} · 평년 대비 #{평년비2} · 지난주 대비 #{주간비2}
- 새우젓 #{수량3} #{금액3} · 평년 대비 #{평년비3} · 지난주 대비 #{주간비3}

■ 11월 구매 재료 가격 흐름
- 배추 #{수량4} #{금액4} · 지난주 대비 #{주간비4}
- 무 #{수량5} #{금액5} · 지난주 대비 #{주간비5}
- 쪽파·대파·생강: #{기타요약}

※ 이번 주 가격 미조사: #{미조사품목}
※ 출처: 한국농수산식품유통공사 KAMIS. 다음 안내는 #{다음발송일}입니다.
```

정보성 메시지 기준에 맞춰 "사도 좋음" 같은 구매 권유 문구는 알림톡에 넣지 않습니다(문자 본문에는 판정이 남아 있음 — 아래 판정 규칙).

### 변수 ↔ 코드 대응

| 변수 | 값 | 비고 |
|---|---|---|
| `#{기준일}` | `10/20(월)` | 가격 기준일(주말·공휴일이면 직전 평일) |
| `#{가족기준}` | `items.json` 의 `family` | |
| `#{총액}` | 가격이 있는 재료의 `now_cost` 합 | `1.4만원` / `9,800원` |
| `#{주간증감}` `#{연간증감}` | 비교 시점 가격이 있는 재료끼리 합산한 증감률 | `+3%` `-2%` `0%`, 비교값 없으면 `-` |
| `#{수량n}` `#{금액n}` `#{평년비n}` `#{주간비n}` | 슬롯 n 재료 | n=1~3 은 `alimtalk.slots`, 4~5 는 `alimtalk.later_slots`(평년비 없음) |
| `#{기타요약}` | `alimtalk.etc` 재료를 `생강 1,824원(+1%) · 대파 …` 한 줄로 | 전부 없으면 `이번 주 가격 없음` |
| `#{미조사품목}` | 가격을 못 찾은 재료 이름 | 없으면 `없음` |
| `#{다음발송일}` | 실행일 기준 다음 주 월요일 | cron 요일을 바꾸면 `next_send_day(weekday=…)` 도 바꿀 것 |

가격이 없는 재료의 슬롯은 `-` 로 채웁니다(알림톡은 변수가 하나라도 비면 접수가 거절되므로 항상 전부 채움).
**슬롯 순서를 바꾸거나 재료를 바꾸면 템플릿 본문도 바뀌므로 카카오 재검수가 필요합니다.** `items.json` 의 `alimtalk` 와 템플릿을 같이 고치세요.

### 읽기 쉬운 템플릿 v2 (재검수용, `templates/alimtalk_v2.txt`)

2026-10 검수본은 한 줄에 값 4개가 붙어 휴대폰에서 "지난주 대\n비"처럼 끊긴다. v2 는 품목명·금액 한 줄, 비교값 한 줄로 나눴다.
**변수 이름은 검수본과 같아서 코드 변경 없이** 템플릿 ID만 바꾸면 된다(`.env` 의 `KAKAO_TEMPLATE_ID`). 치환 후 약 390자(알림톡 한도 1,000자).

### 눈에 잘 들어오는 템플릿 v3 (강조표기형, `templates/alimtalk_v3.txt`)

카카오 알림톡의 **강조표기형**을 써서 맨 위에 예상 재료비(`약 #{총액}`)를 큰 글씨로 띄우고, 본문은 구역선(━)·이모지 소제목·품목별 3줄(이름·수량 / 금액 / 비교)로 나눴다.
증감은 `▲3%`(올라감) `▼2%`(내려감) `변동 없음` 으로 표시한다(v1·v2 템플릿에도 같이 적용됨). 변수는 v1·v2 와 같아서 코드 변경 없이 템플릿 ID만 바꾸면 된다.
등록 방법: 솔라피 → 알림톡 템플릿 등록 → 강조 유형 "강조표기형" → 강조 제목·보조문구·본문 칸에 파일의 각 부분을 붙여 넣기.

### 최소형 템플릿 v6 (추천, `templates/alimtalk_v6.txt`)

기준은 하나: 부모님이 10초 안에 "올해 얼마 들고, 지금 뭘 사야 하나"를 알 수 있는가. 이모지·범례·구분선·섹션 제목 없이 여덟 줄. 재료당 한 줄, 비교는 숫자 대신 말로 — `#{평년말n}` (`평년보다 7% 쌈` / `평년 수준` / `평년보다 10% 비쌈`), 보조문구에 `#{연간말}` (`작년보다 6% 쌈`), 11월 채소는 배추·무 한 줄씩 `#{주간말n}` (`지난주보다 3% 내림`), 파·생강은 `#{기타금액} · #{기타말}`. 권유 문구는 없고 사실 한 마디가 결정 근거가 된다(공모전 취지: KAMIS 가격 정보로 구매 시기 결정). 변수 22개, 치환 후 약 230자.

### 간결형 템플릿 v5 (`templates/alimtalk_v5.txt`)

한눈에 들어오는 것 두 가지만 남겼다: **총액**과 **지금 살 양념이 싼지 비싼지**. 재료당 한 줄(`🟢 깐마늘 1.2kg 1.4만원 · 작년 ▼7%`), 평년 대비는 색 표시 `#{표시n}`(🟢 -3% 이하 · ⚪ · 🔴 +3% 이상 · ⚫ 자료 없음)와 범례 한 줄, 작년 대비 `#{연간비n}` 하나만 붙인다. 11월 채소는 `#{채소금액} #{채소주간} #{채소연간}` 합계 한 줄. 치환 후 약 230자. 상세 숫자는 문자 본문과 보고서에 남긴다.

### 상태 줄이 있는 템플릿 v4 (강조표기형, `templates/alimtalk_v4.txt`)

v3에 재료별 **상태 줄** `#{상태1~3}` 을 더했다: `🟢 평년보다 낮음 · 하락 중`, `🔴 평년보다 크게 높음`, `⚪ 평년 수준`. 평년비·주간비 숫자를 부모님이 해석하지 않아도 되게 말로 풀되, "사세요" 같은 권유는 넣지 않아 정보성 기준을 지킨다(기준: 평년 대비 -3% 이하 낮음, +3% 이상 높음, +10% 이상 크게 높음; 지난주 대비 ±3% 이상이면 하락/상승 중).
그 밖에 줄 앞 들여쓰기 제거(카톡이 공백을 접음), 구분선 10자(두 줄로 꺾임 방지), 강조 보조문구를 가족 기준으로 바꿨다. **변수가 3개 늘어 v4 템플릿에는 코드 변경이 포함된 이 버전이 필요하다.** v1~v3 템플릿으로 보낼 때는 `#{상태n}` 이 템플릿에 없어도 솔라피가 쓰지 않는 변수는 무시하므로 그대로 동작한다. 치환 후 약 420자.
이모지(🌶 🥬)가 검수에서 반려되면 빼고 다시 올리면 된다(구역선·▸·▲▼는 일반 특수문자).

### 값 표기 규칙
- 오르면 `▲3%`, 내리면 `▼2%`, 반올림해서 0% 면 `변동 없음`, 비교 시점 가격이 없으면 `자료 없음` (`-` 한 글자는 뜻이 안 보여서 쓰지 않음)
- 이번 주 가격을 못 찾은 재료는 금액 `가격 없음`, 이름은 `#{미조사품목}` 에
- KAMIS 의 "1주일 전" 칸은 그날이 공휴일이면 비어 있다(예: 10/16 기준 → 10/9 한글날). 이때는 7일 전부터 거슬러 올라가
  가격이 있는 가장 가까운 영업일과 비교한다(`fill_week`, 로그의 `week_from` 에 실제 비교일).

### 설정 순서

1. 솔라피에 카카오 비즈니스 채널 연동 (사업자 채널) → **채널 ID(pfId)** 확인
2. 솔라피 알림톡 템플릿 등록: 위 본문을 그대로 붙여 넣고 검수 요청 → 승인 후 **템플릿 ID** 확인
3. `.env` 에 `KAKAO_PF_ID`, `KAKAO_TEMPLATE_ID` 채움 (`SOLAPI_KEY`, `SOLAPI_SECRET`, `SMS_FROM`, `SMS_TO` 는 그대로 사용)
4. `python3 kimjang_report.py vars` 로 변수 값이 전부 채워지는지 확인 → 솔라피 템플릿 테스트 발송에 붙여 넣어 미리보기
5. `./run.sh` 로 실제 1건 발송 → 수신 확인

### 발송 규칙 (`notify.py`)

- `KAKAO_PF_ID` 와 `KAKAO_TEMPLATE_ID` 가 둘 다 있으면 **알림톡**으로 보내고, 문자 채널은 건너뜁니다.
  알림톡이 실패하면(채널 미추가·수신 거부 등) 솔라피가 같은 번호로 **문자(LMS)를 자동 대체 발송**하므로 중복이 생기지 않습니다. 대체 문자 본문은 `messages/날짜.txt` 와 같습니다.
- 둘 중 하나라도 비어 있으면 예전처럼 **문자**로 보냅니다(90바이트 초과 시 LMS 자동 전환).
- 메일(`SMTP_*`, `MAIL_TO`)과 텔레그램(`TELEGRAM_*`)은 값이 있으면 추가로 보냅니다. 한 채널이 실패해도 나머지는 계속 보내고, 저장은 항상 됩니다.

## 5. 매주 자동 실행 (cron)

```
TZ=Asia/Seoul
0 9 * * 1  /경로/kimjang-price-report/run.sh >> /경로/kimjang-price-report/data/cron.log 2>&1
```

매주 월요일 9시. 당일 가격은 보통 오후에 올라오므로 월요일 아침에는 직전 금요일 가격으로 리포트가 만들어집니다.
`run.sh` 는 실행 전에 `git pull --ff-only` 로 최신 코드를 받습니다. 서버에 커밋되지 않은 수정이 있으면 pull 을 건너뛰고 경고만 남기며, `NO_PULL=1 ./run.sh` 로 끌 수 있습니다.

## 판정 규칙 (문자·메일 본문의 "지금 사 둘 재료")

| 조건 | 문구 |
|---|---|
| 평년 가격 이하 | 사도 좋음 |
| 지난주보다 3% 이상 내림 | 1~2주 더 지켜보기 |
| 평년보다 10% 이상 비쌈 | 필요한 만큼만 |
| 그 외 | 사도 무방 |

배추·무처럼 11월에 사는 재료는 판정 없이 가격 흐름만 보여 줍니다. 알림톡에는 판정 문구가 들어가지 않습니다.
