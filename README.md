# 김장 물가 알리미

KAMIS Open API 소매가격으로 김장 재료 예상 비용과 구매 판단을 주 1회 정리하는 스크립트입니다. Python 3.8 이상, 표준 라이브러리만 씁니다.

## 1. 인증 정보

```bash
cp .env.example .env
nano .env        # KAMIS 키와 문자 발송 정보 입력
chmod 600 .env
```

`.env`는 `.gitignore`에 들어 있어 커밋되지 않습니다.

## 2. 품목 이름 확인 (처음 한 번)

```bash
set -a; . ./.env; set +a
python3 kimjang_report.py codes
```

채소류·특용작물·수산물의 품목, 품종, 등급, 단위가 출력됩니다. `items.json`의 `category`, `match_item`, `match_kind`를 실제 출력과 맞추세요. 단위가 다르면(예: 고춧가루가 1kg이 아니라 600g) 스크립트가 자동 환산하고, 개/포기처럼 무게로 바꿀 수 없는 경우만 "단위 불일치"로 알려 줍니다. 수량(`qty`)은 부모님 댁 김장 기준으로 고치세요.

## 3. 리포트 만들기

```bash
./run.sh --no-send                 # 발송 없이 생성만 (처음엔 이걸로 확인)
./run.sh                           # 생성 + 발송
./run.sh --fixture sample --no-send # 인터넷 없이 가짜 숫자로 시험
```

결과는 `data/` 폴더에 쌓입니다. 보고서 그래프와 증빙에 그대로 씁니다.

- `messages/날짜.txt`: 부모님께 보낼 문구. 카톡이나 문자에 붙여넣기
- `logs/날짜.json`: 그날 조회한 원자료
- `prices.csv`: 주차별 가격 누적. 엑셀에서 바로 열림

## 발송 채널

`notify.py`가 `.env`에 값이 있는 채널로만 보냅니다. 기본은 문자(솔라피)이고, 메일과 텔레그램은 선택입니다. 알림톡은 사업자 채널이 필요해 개인은 쓸 수 없으므로 문자로 대신합니다. 90바이트를 넘으면 솔라피가 LMS로 자동 전환합니다.

솔라피 준비: 회원가입 → 발신번호 등록(본인 휴대폰 인증) → API Key 발급 → 충전(건당 수십 원). 요금과 절차는 가입 시점에 다시 확인하세요.

## 4. 매주 자동 실행 (cron)

```
TZ=Asia/Seoul
0 9 * * 1  /경로/kimjang-price-report/run.sh >> /경로/kimjang-price-report/data/cron.log 2>&1
```

매주 월요일 9시에 실행합니다. 당일 가격은 보통 오후에 올라오기 때문에 월요일 아침에는 직전 금요일 가격으로 리포트가 만들어집니다.

## 판정 규칙 (9~10월에 사는 재료)

| 조건 | 문구 |
|---|---|
| 평년 가격 이하 | 사도 좋음 |
| 지난주보다 3% 이상 내림 | 1~2주 더 지켜보기 |
| 평년보다 10% 이상 비쌈 | 필요한 만큼만 |
| 그 외 | 사도 무방 |

배추·무처럼 11월에 사는 재료는 판정 없이 가격 흐름만 보여 줍니다.
